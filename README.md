# Crazy Rush — المرحلة 1

لعبة سباق ثلاثية الأبعاد (Godot 4.5، GL Compatibility، أفقي على أندرويد).
المرحلة 1: فوكسي ثلاثي الأبعاد، مسار جسر خشبي، جري تلقائي، توجيه حر، قفز، انزلاق، لكمة، كاميرا خلفية.

- كل المجسمات مبنية بالكود (أصلية، بلا أصول خارجية) + خط Cairo (OFL).
- الاختبارات: `godot --headless -s tests/run_tests.gd`
- بناء APK تلقائي عبر GitHub Actions → Releases → `phase1-latest`.
- الإعدادات: جودة منخفضة/متوسطة/عالية، خفض تلقائي للجودة، عدّاد FPS.
